# 作業チェックリスト

作業ごとに開始・終了時刻を記録できる、ブラウザだけで動くチェックリストアプリです。

## 公開URL

https://work-checklist-7pz.pages.dev/

## 主な機能

- 作業の新規登録・編集・削除
- ▶ / ■ ボタンで開始・終了を記録、↺ でリセット
- ドラッグで並べ替え
- CSV エクスポート / インポート
- スマホ表示に対応

データはブラウザの localStorage に保存されます。サーバーには送信されません。

## 使い方

### 準備する

- 「作業タイトル」は好きなタイトルに変更できます。
- 「新規登録」ボタンを押すことで、チェックリストカードを作成できます。作業を始める前に、予め作成しておくことができます。
- 作成したチェックリストカードの順番を並び替えることができます。作業段取りを見直す場合に便利です。

### 作業する

- 実際に作業するときにスタートボタン（▶）を押すと、ステータスが「進行中」になり、作業時間の計測が開始されます。
- ストップボタン（■）を押すと、ステータスが「完了」になり、作業時間が計算されます。
- ステータスが「完了」の場合は、スタートボタンは押せなくなります。もう一度時間計測したい場合は、リセットボタン（↺）を押します。
- 時間計測しないでステータスを変更したい場合は、プルダウンでステータスを変更できます。

### 記録を残す・再利用する

- CSVエクスポートすることで、作業記録を残すことができます。この場合、ファイル名は「作業タイトル + 日付」となります。
- 次回以降、同じチェックリストカードの一覧を使いたい場合、インポートすることで同じ作業手順で作業することができます。インポートのファイル名が作業タイトルに反映されます。ただし、開始・終了時刻・所要時間、作業日付はリセットされ、ステータスは「未着手」となります。

## ひとこと

サーバー再起動など、作業用のチェックリストが必要なケースがあるので、その都度チェックリストを作成していましたが、その時間を効率化できないかと常々思っていました。

工夫した点は、過去に使ったチェックリストを使いまわせることと、ドラッグアンドドロップで順番を入れ替えられるようにしたことです。これにより、以前やった作業を一から思い出す時間を省くことができ、より効率的な作業段取りを計画することができます。

難しかった点は、ユーザーの視点に立ってどのような使い方をするのかイメージしながら、どのような機能やパーツが必要か、過剰な機能を作っていないか、どうやったら作業を効率化できるか、といった全体的なことを考えることでした。
